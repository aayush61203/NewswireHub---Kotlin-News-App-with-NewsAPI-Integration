An elegant **Android News App** built in **Kotlin**, powered by [NewsAPI.org](https://newsapi.org).  
It fetches real-time news, allowing users to filter by **Country** and **Category**.  
Default Country: **India 🇮🇳**, Default Category: **General**.  
Smooth **sharing**, **viewing**, and **navigation** experience!

---

## ✨ Features

- 🌍 **Country & Category Filter**  
  - Default: India 🇮🇳 | General News  
  - Choose your interest and region.
  
- 📰 **News Display**  
  - Thumbnail image, Headline, Author, Place, Published Date.
  - Smooth, clean layout for better readability.
  
- 🔗 **Open Full Article**  
  - Tap any news to open the full source.

- 📤 **One-Tap News Sharing**  
  - Long-press to directly open share window.
  - Shared message includes: Heading, Author, Place, Published Date, and URL.
  
- 🎨 **Modern UI/UX**  
  - Clean and attractive design.
  - Fast and responsive performance.

## 🚀 How to Use the APK (Normal User Guide)

1. **Click** on the [Download APK](https://github.com/aayush61203/NewswireHub---Kotlin-News-App-with-NewsAPI-Integration/releases/download/v1.0/base.apk) button.
2. **Install** the APK on your Android device.
   - If prompted, allow installation from unknown sources.
3. **Open** the app.
4. **Browse News**:
   - Default country is India 🇮🇳 and category is General.
   - Change filters easily from the options.
5. **Click** any news to **read full story**.
6. **Long Press** any news card to **share it instantly**.

Enjoy seamless, personalized news updates! 📱

## 👨‍💻 How Developers Can Use this Project

### 🛠️ Prerequisites

- Android Studio (latest version recommended)
- Kotlin Plugin
- An API key from [NewsAPI.org](https://newsapi.org/)

### ⚙️ Setup Steps

1. **Clone this repo**:
   ```bash
   git clone https://github.com/aayush61203/NewswireHub---Kotlin-News-App-with-NewsAPI-Integration.git
   ```
2. Open the project in Android Studio.

3. Get your API key from NewsAPI.org.

4. Replace API key in the project:

    Find the file where API key is used (likely in RetrofitInstance.kt or similar).

    Insert your API key.

5. Build and Run the app on an emulator or real device.
